# Oracle Exam Practice — Mac installation

Plug-in version 1.1.0 — Mac installer revision 3

The installer includes the plug-in, dependencies, and Node.js runtimes for Apple Silicon and Intel. It selects the appropriate runtime automatically. Setup requires macOS 13.5 or newer, uses your own account, and needs no administrator access or downloads. You still need a compatible ChatGPT/Codex desktop host with local plug-in and MCP Apps UI support; installer CPU support does not establish host availability on an Intel Mac.

## Install

1. Download **Oracle-Exam-Practice-Mac-Installer.zip** and double-click it to extract the folder.
2. In that folder, double-click **Oracle-Exam-Practice-Setup.command**. It opens in Terminal. If macOS blocks it because it is unsigned, follow the security approval steps below before continuing.
3. Review the setup description, type **y**, and press Return. You should next see **Verifying bundled installer files...**, **Starting file installation and plug-in checks...**, and **Installing to** followed by a folder path.
4. Wait for **FILES AND CATALOG VERIFIED — CHATGPT ACTIVATION REQUIRED**, then press Return. The installer saves a setup report and a plug-in-opening helper in the extracted installer folder. File setup is complete; ChatGPT activation is still required.
5. Fully quit ChatGPT using **ChatGPT → Quit ChatGPT** or **Command-Q**, then reopen it. Closing its window alone is not the same as quitting.
6. Use the **Plug-Ins** item in the left menu and select the **Personal** tab.
7. Install/enable **Oracle Exam Practice**, start a new chat, select the plug-in, and ask: **“Open Oracle Exam Practice.”**

No API key or additional plug-in settings are needed. Internet access is required for ChatGPT and Oracle-source research when generating an exam. This local installer does not create a connection for browser-only ChatGPT.

If Oracle Exam Practice is absent from Personal, double-click **Open-Oracle-Exam-Practice.webloc** in the extracted installer folder. It opens the local plug-in detail page using the exact catalog path generated by setup. Complete **Install/Enable** there, then fully quit/reopen ChatGPT and check Personal again. If macOS says no application can open that helper, the desktop host does not handle the local plug-in link on that machine; file copying alone has not confirmed host registration.

The ZIP preserves executable permissions. If a transfer method removes them, open Terminal, type `bash ` (with a trailing space), drag the `.command` file into the window, and press Return. Run setup as your normal Mac user, **without sudo**.

## macOS security approval

This installer is **not signed or notarized**. Where your organization permits running this reviewed installer:

1. Try opening the `.command` file once, then dismiss the macOS warning.
2. Open **Apple menu → System Settings → Privacy & Security**.
3. Find the message about the blocked installer and select **Open Anyway**.
4. Authenticate if asked, review the file name, and confirm **Open**.
5. Return to setup and continue.

These steps approve that specific file; do not disable Gatekeeper or override an explicit malware warning. If approval is unavailable or company policy blocks it, have IT review/sign/notarize the distribution. A newly downloaded revision may require approval again. [Apple's instructions](https://support.apple.com/en-us/102445).

## Use

Enter the exact Oracle exam name and ID, wait for 50 researched questions, select your answers, and choose **Submit for grading**. Review your percentage score and the linked explanations for missed answers. **Download results** saves a private copy.

Repeated exam requests create fresh sets. No more than 20 questions may match recent wording fingerprints; ChatGPT is also instructed to vary scenarios and reasoning. AI-generated practice material may contain errors and is not an official Oracle exam.

## Updates and troubleshooting

- Run the new installer to update its catalog entry. If the desktop app still shows an older version, reinstall the plug-in from that catalog, fully restart, and begin a new chat.
- If the plug-in is missing, use **Plug-Ins → Personal**, confirm you used **Command-Q**, then try the `.webloc` helper. Account/workspace restrictions can still prevent activation.
- If Terminal jumps straight from your **y** answer to **Press Return to close this installer**, setup did not run. Download installer **revision 3**, extract it into a new folder, and run that copy. Revision 3 fixes a startup problem with alternate temporary-folder paths on macOS and reports an error if setup exits without a completion receipt. The `.webloc` helper and setup report are created during successful setup; they are not included in the ZIP.
- First look **beside the extracted installer**, rather than browsing hidden folders. Revision 3 creates **Oracle-Exam-Practice-Installer-Transcript.log**, **Oracle-Exam-Practice-Setup-Report.txt**, and **Open-Oracle-Exam-Practice.webloc**. The report lists the exact profile, installation, catalog, and application-check log paths. If that folder is not writable, the installer prints its fallback log/report location.
- To find a printed path, use **Finder → Go → Go to Folder** (**Shift-Command-G**) and paste the full path from the report. `Library` and dot-prefixed folders may be hidden. The catalog is not at `/marketplace.json`.
- Normal locations are `/Users/<your-user>/.agents/plugins/marketplace.json` and `/Users/<your-user>/Library/Logs/OracleExamPractice/`, but use the actual report paths. Setup uses the operating-system account's home and refuses to run as root, avoiding an accidental installation under `/var/root`.
- Versioned source folders remain under the reported profile's `.codex/plugins/` directory. Existing catalog entries/policies are preserved and backed up. If the report says verification succeeded but its catalog file cannot be found at that exact path, send the report and transcript to support; do not assume ChatGPT is connected.
- Existing exam data is not removed by setup. It remains separately under `~/.oracle-exam-practice/`.

**Validation:** revision 3 fixes a reproduced silent exit when the installer starts through an alternate folder path, including macOS’s `/var` versus `/private/var` temporary-folder paths. Nine installer tests pass, including startup through an alternate path and a full installation that produces the catalog, report, helper, and completion receipt. The application’s sixteen checks also pass. These tests were run on Windows; native Mac execution, plug-in discovery, and link handling still need the Mac tester’s confirmation. File/catalog verification does not prove that the UI has installed/enabled the plug-in.

Runtime compatibility: [Node.js 24.15.0 supported platforms](https://github.com/nodejs/node/blob/v24.15.0/BUILDING.md#platform-list). Local catalog setup: [OpenAI plug-in packaging](https://developers.openai.com/plugins/build/plugins#install-a-local-plugin-manually).
